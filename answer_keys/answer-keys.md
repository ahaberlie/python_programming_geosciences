# Answer Keys

Select a homework or exercise below to view a worked solution. To run the code, open the matching notebook in Jupyter and run its cells from top to bottom. Exercise 1 uses Markdown. The plotting notebooks require Matplotlib, the array notebooks require NumPy, and the pandas notebooks use the course CSVs in the repository's `data/` directory.

The keys contain one worked solution per prompt. The examples in Exercise 1 and Homework 4 are illustrative. The pandas and NumPy keys retain the assignment graders where provided.
